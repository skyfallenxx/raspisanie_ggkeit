# Бот «Расписание с заменами»

Бот запоминает основное расписание на неделю и применяет замены к выбранной дате. Каждая группа и подгруппа ведёт общее расписание. Интерфейс на русском, часовой пояс по умолчанию — Минск.

## Запуск на Android

1. Установи [Termux из F-Droid](https://f-droid.org/packages/com.termux/) и открой приложение. Сохрани `telegram-schedule-android.zip` в папку **Загрузки (Downloads)** на телефоне.
2. Выполни в Termux эти команды по порядку. После первой разреши Termux доступ к файлам. Если телефон сохранил архив под другим именем, подставь его в третьей команде.

   ```bash
   termux-setup-storage
   pkg install -y unzip
   unzip -o ~/storage/downloads/telegram-schedule-android.zip -d ~
   cd ~/telegram-schedule
   bash start-android.sh
   ```

3. При первом запуске скрипт установит нужные пакеты и загрузит модели для русского и английского. После установки вставь токен от [@BotFather](https://t.me/BotFather) прямо в Termux и нажми Enter. Если бот уже создан, используй тот же токен и перед этим останови его копию на ПК. Если бота ещё нет, создай его через `/newbot`.
4. Открой ссылку на бота, которую напечатает Termux, и нажми **Start**. Затем сверни Termux и проверь, что бот отвечает после блокировки экрана.

Для работы в фоне скрипт включает `termux-wake-lock`. В настройках Android открой **Приложения → Termux → Батарея** и выбери **Без ограничений**, если такой режим доступен. Не останавливай Termux принудительно. Телефону нужен интернет. После перезагрузки или если Android остановит Termux, запусти бота снова. Android может ограничивать работу в фоне даже с отключённой оптимизацией. [Ограничения Android](https://developer.android.com/training/monitoring-device-state/doze-standby), [справка Termux](https://github.com/termux/termux-app).

Чтобы снова запустить бота, выполни `cd ~/telegram-schedule && bash start-android.sh`. Для остановки нажми **Ctrl+C** в Termux. Для белорусских названий запусти `OCR_LANG=rus+bel+eng bash start-android.sh`.

Если уже ввёл расписание на ПК, останови бота и скопируй папку `data` из старой установки в `~/telegram-schedule/` через Termux. Если папка `data` лежит в **Загрузках** на телефоне, команда для переноса — `cp -r ~/storage/downloads/data ~/telegram-schedule/`. При переносе на телефоне ещё не должно быть сохранённого расписания.

## Запуск на Windows

1. Распакуйте архив в отдельную папку. Создайте бота командой `/newbot` у [@BotFather](https://t.me/BotFather) и скопируйте выданный токен. [Инструкция Telegram](https://core.telegram.org/bots/tutorial).
2. Если на компьютере нет Node.js 22 или новее, установите его с [сайта Node.js](https://nodejs.org/en/download). Для ввода текстом этого достаточно.
3. Для фотографий установите Tesseract OCR с языками **Russian (rus)** и **English (eng)**. Для чтения белорусских названий добавьте **Belarusian (bel)** и задайте переменную среды `OCR_LANG=rus+bel+eng`. Бот ищет Tesseract в стандартной папке Windows и в `PATH`. Если выбрали другую папку, укажите полный путь к `tesseract.exe` в переменной среды `TESSERACT_PATH`. [Установка Tesseract](https://tesseract-ocr.github.io/tessdoc/Installation.html).
4. Откройте `start.cmd` и вставьте токен в окно запуска. Ввод скрыт, токен остаётся в памяти текущего процесса. Откройте ссылку на бота из окна запуска и нажмите **Start**. Бот отвечает, пока окно запуска открыто и компьютер подключён к интернету.

## Использование

1. **Загрузить расписание**. Отправьте общий лист ПТО и общий лист ССО одним альбомом или двумя изображениями подряд. Изображения в полном разрешении можно отправить как файлы. Проверьте число листов и список групп в последнем черновике, затем нажмите **Опубликовать расписание**. Студенты увидят опубликованный лист в кнопке **Основное расписание**. Исходное расписание ПТО уже входит в комплект. Текст или отдельное фото для одной подгруппы можно загрузить тем же меню.
2. **Загрузить замены**. Перешлите фото с заменами прямо в чат бота. Выберите дату и подтвердите распознанный черновик. Если основное расписание уже сохранено, можно так же отправить обычное фото. Чтобы внести замены текстом, нажмите **Загрузить замены**, выберите дату и перешлите сообщение или отправьте свой список по номерам уроков. Формат `1, 2. Черчение` меняет оба урока, а `3–5. Информатика` меняет уроки с третьего по пятый. Чтобы снять замену для урока, отправьте `2. по расписанию`.
3. **Сегодня**, **Завтра** или **Другая дата**. Бот покажет итоговый список с номерами уроков, предметами и кабинетами. Отменённый урок будет отмечен в своём слоте. Замены сохраняются на выбранную календарную дату.

При первом входе выберите группу из списка или введите её обозначение, затем выберите подгруппу. Анкета сохраняется для вашего аккаунта. Её можно изменить кнопкой **👤 Моя анкета**. Расписание и замены общие для участников выбранной группы и подгруппы. Кнопка **📥 Получить замены** показывает итоговое расписание на самую позднюю дату с загруженными заменами. Для другой даты используйте календарь.

В общей таблице замен бот ищет группу из вашей анкеты и предлагает проверить оба списка. Одно нажатие **Сохранить** применяет оба показанных списка. Если удалось разобрать только выбранную подгруппу, бот покажет её черновик. Ввод расписания и замен текстом применяется к выбранной подгруппе.

### Пример основного расписания

```text
Понедельник
1. Математика
2. Русский язык
3. География

Вторник
1. История
2. Физика
```

### Пример замен

```text
2. Информатика, каб. 18
3. отмена
```

## Хранение и запуск из терминала

Готовое расписание и замены хранятся в папке `data`, которая создаётся при первом сохранении. Если переносите бота, скопируйте и эту папку. Фотографии распознаются на компьютере, где запущен бот. Подтверждайте черновик до перезапуска.

На сервере с Node.js 22+, Tesseract и языковыми пакетами `rus` и `eng` задайте `TELEGRAM_BOT_TOKEN` в окружении и запустите `node bot.mjs`. Запускайте один экземпляр на токен. Для другого часового пояса задайте `SCHEDULE_TZ` в формате IANA, например `Europe/Moscow`.

В Windows обработка снимка использует встроенный Windows PowerShell. В Termux скрипт запуска устанавливает ImageMagick. На Linux для обработки снимков установите ImageMagick 7 с командой `magick`.
